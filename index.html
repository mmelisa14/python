Primii pași în Python

Python este un limbaj de programare creat de Guido van Rossum (prima versiune în 1991). Este citit aproape ca engleza, are puține reguli de sintaxă și este folosit în web, analiză de date, inteligență artificială, automatizări, jocuri și științe.

Cum rulează un program Python

Python este un limbaj interpretat: un program numit interpretor citește codul linie cu linie și îl execută. Nu trebuie să îl compilezi manual. Ai trei moduri obișnuite de lucru:

  • Fișier .py: scrii codul într-un fișier (de exemplu program.py) și îl rulezi din terminal cu python program.py.
  • Consola interactivă (REPL): scrii python în terminal și testezi comenzi una câte una.
  • Editor sau notebook: VS Code, PyCharm, Thonny (bun pentru începători) sau Jupyter.
Cum funcționează site-ul acesta. Codul din paginile următoare rulează direct în browser, cu un interpretor Python scris în JavaScript (Skulpt). Este Python 3 și acoperă aproape tot ce înveți la nivel de început și mediu. Câteva module (de exemplu json, os, statistics) nu există în el; exemplele cu ele sunt marcate doar de citit și le poți încerca pe calculatorul tău.

Primul program: print()

print() afișează text pe ecran. Textul se scrie între ghilimele, simple sau duble.

Observă că "5 + 3" între ghilimele ar fi fost text, iar fără ghilimele 5 + 3 este calculat și se afișează 8. Ghilimelele spun Python-ului „asta este text, nu o operație”.

Comentarii

Tot ce urmează după # pe o linie este ignorat de Python. Comentariile sunt notițe pentru oameni.

Reguli de bază ale sintaxei

  • Python deosebește literele mari de cele mici: Print nu este același lucru cu print.
  • Indentarea contează. Blocurile de cod (după if, for, def etc.) se marchează prin spații la începutul liniei, nu prin acolade. Standardul este 4 spații.
  • O instrucțiune stă de obicei pe o linie; nu e nevoie de ; la final.
  • Un bloc începe după o linie care se termină cu două puncte :.

Erorile sunt normale

Când greșești, Python afișează un mesaj cu tipul erorii și numărul liniei. Citește-l: de obicei îți spune exact ce nu merge. Cele mai frecvente la început:

Exerciții

Variabile

O variabilă este un nume atașat unei valori din memorie. O creezi cu semnul =, fără să declari tipul în prealabil.

Declarare și atribuire

În Python nu scrii int varsta ca în C sau Java. Tipul îl are valoarea, nu numele. Se numește tipare dinamică: același nume poate arăta apoi spre o valoare de alt tip.

= nu înseamnă „egal” ca în matematică, ci „pune valoarea din dreapta în numele din stânga”. De aceea merge și asta:

Cum gândești o variabilă

Imaginează-ți o etichetă lipită pe o cutie. a = [1, 2] creează lista și lipește eticheta a pe ea. b = a lipește o a doua etichetă pe aceeași cutie, nu face o copie. Vei vedea importanța la liste.

Reguli pentru nume

  • Poate conține litere, cifre și _, dar nu poate începe cu cifră: 1x este invalid, x1 este valid.
  • Fără spații sau simboluri (-, $, @…).
  • Majusculele contează: Scor, scor și SCOR sunt trei variabile diferite.
  • Nu poți folosi cuvinte rezervate: if, for, class, None, True, def, return… (lista completă: import keyword; keyword.kwlist).

Convenții (PEP 8)

  • Variabile și funcții: snake_case cu litere mici: numar_elevi.
  • Constante (valori care nu se schimbă): MAJUSCULE: PI = 3.14159. Python nu le blochează, e doar o înțelegere între programatori.
  • Clase: CamelCase: ContBancar.
  • Nume sugestive: pret_total, nu x sau a1.

Exerciții

Tupluri (tuple)

Un tuplu este ca o listă, dar imutabil: odată creat, nu îl mai modifici. Se folosește pentru grupuri fixe de valori (coordonate, date calendaristice, rezultate multiple din funcții).

Despachetare (unpacking)

De ce tupluri, dacă avem liste?

  • Sunt puțin mai rapide și ocupă mai puțină memorie.
  • Semnalează „aceste valori nu se schimbă”.
  • Pot fi chei de dicționar sau elemente de mulțime (listele nu pot).

Exerciții

Dicționare (dict)

Un dicționar asociază chei cu valori, ca într-un dicționar real: cauți după cuvânt, găsești explicația. Căutarea după cheie este foarte rapidă.

Cheile trebuie să fie imutabile (șiruri, numere, tupluri) și unice. Valorile pot fi orice, inclusiv alte dicționare sau liste. De la Python 3.7, dicționarele păstrează ordinea inserării.

Exerciții

Funcții

O funcție este un bloc de cod cu nume, pe care îl scrii o dată și îl folosești de câte ori vrei. Evită repetarea și face programele mai clare.

Dacă o funcție nu are return (sau are return simplu), întoarce None. return oprește imediat funcția.

print vs return. print doar arată o valoare pe ecran; return o dă înapoi codului care a apelat funcția, ca să o poată folosi mai departe. Majoritatea funcțiilor trebuie să returneze, nu să afișeze.

Tipuri de parametri

Capcană: nu folosi o listă ca valoare implicită (def f(x=[]):). Obiectul este creat o singură dată și partajat între apeluri. Folosește x=None și creează lista în interior.

Domeniu de vizibilitate (scope)

Regula: variabilele create într-o funcție există doar în ea. Preferă să dai valorile ca parametri și să primești rezultatul prin return.

Docstring și funcții care cheamă funcții

Recursivitate

O funcție recursivă se apelează pe ea însăși. Are nevoie de un caz de bază (unde se oprește) și de un pas recursiv care se apropie de cazul de bază.

Funcții lambda

O funcție anonimă, scurtă, pe o singură expresie. Folosită mai ales ca argument pentru sorted, map, filter.
